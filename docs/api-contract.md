# Initial API contract

The API is served at `http://localhost:8000`. Interactive documentation is available at `/docs`.

| Method | Path | Foundation behavior |
|---|---|---|
| GET | `/health` | Returns service status and application name |

Planned routes, added in later phases: authentication, meeting input and retrieval, transcription, extraction, task review and approval, dashboard queries, reminders, and simulated Slack/Calendar actions.
